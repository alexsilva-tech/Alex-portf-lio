# Portfólio de UI/UX

Aplicação web de portfólio criada para apresentar projetos de identidade visual, campanhas e interfaces digitais. O projeto prioriza navegação fluida, composição editorial e uma experiência responsiva.

> **Nota:** os cases e informações de contato exibidos na interface são demonstrativos e devem ser substituídos antes de uma publicação comercial.

## Destaques

- Interface responsiva com React e TypeScript
- Animações e transições de interface com Motion
- Ícones com Lucide React
- Organização centralizada de conteúdo em `src/data/portfolioConfig.ts`
- Construção com Vite

## Tecnologias

- React 19
- TypeScript
- Vite
- Motion
- Tailwind CSS
- Lucide React

## Executar localmente

```bash
npm install
npm run dev
```

O aplicativo ficará disponível em `http://localhost:3000`.

## Scripts

| Comando | Descrição |
| --- | --- |
| `npm run dev` | Inicia o ambiente de desenvolvimento |
| `npm run build` | Gera a versão de produção |
| `npm run preview` | Visualiza localmente a versão de produção |
| `npm run lint` | Verifica os tipos com TypeScript |

## Personalização

Os projetos, serviços, experiências, imagens e contatos ficam concentrados em:

```
src/data/portfolioConfig.ts
```

Atualize esse arquivo com informações reais antes de usar o projeto como portfólio profissional.
